# Claude Code Configuration

## Financial Services Plugins

This project has the following financial services plugins installed:

- **financial-analysis** - Financial modeling, DCF, LBO, comps, 3-statement models, deck QC
- **equity-research** - Earnings analysis, initiating coverage, morning notes, sector reports
- **investment-banking** - CIM drafting, pitch decks, merger models, buyer lists, deal tracking
- **wealth-management** - Financial plans, client reports, portfolio rebalancing, TLH
- **private-equity** - IC memos, due diligence, LBO returns, portfolio review, deal sourcing

These plugins are sourced from the `financial-services-plugins` marketplace and provide specialized skills for financial analysis workflows.
